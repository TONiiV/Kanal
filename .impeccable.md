# Kanal design context

For desktop UI work, read [Current UI design](docs/design/ui-design.md), confirmed on 2026-10-05.
It takes precedence over earlier visual proposals and prototype layouts. Use
[meeting workspace](docs/design/meeting-workspace.md) for unchanged interaction constraints and
[Conversation K](docs/design/conversation-k.md) for brand asset generation and mobile rules.

The operator works during technical Chinese/German/Polish meetings; participants glance at a
read-only translated transcript on their phones. Part numbers, tolerances, dates and speaker
identity must remain legible. The product should feel precise, approachable and calm.

Mobile supports both colour schemes. Preserve the one-control mobile reading flow and the
recording-consent and pause boundaries.

The hard constraints in [`CLAUDE.md`](CLAUDE.md#hard-constraints) — fonts, font-stack order, offline
cache, PRD-frozen layout, Avalonia limits, explicit light brushes — apply to every UI change.
