# Kanal：Conversation K 视觉系统

2026-09-23。用户确认 G 版「折带 K＋双向对话」作为新 UI 的形状基线，并要求继续比较配色。
本次工作在 `.worktree/new-ui` / `codex/new-ui` 中进行。

## 品牌与使用场景

K 让图标与 Kanal 名称建立直接关联；相向的两个气泡尖角代表多语言对话。
折带的连接与留白提供视觉特征，界面只借用它的颜色、柔和转角与空间关系，
不会把转写内容包装成大面积气泡。

目标仍是让操作者边开会边操作、让参与者快速读懂翻译。
技术术语、零件编号、容差及中德波三种文字的可读性优先。

## 形状、排版与布局

- 保留已确认的三栏工作空间、可收起侧栏、固定位置的录制控件与转写刻度尺。
- 普通按钮、输入框、选择器使用 8px 圆角；菜单与弹出层 12px；品牌展示容器 16px。
- 录制与暂停保持圆形状态控件，语言旗标保持圆形，正文分隔仍使用直线。
- 用暖纸色区分侧栏与正文，以细线连接顶栏；不用厚黑线分割每个模块。
- Logo 只出现在品牌入口、启动页、关于页及移动端页头，不重复铺入正文。
- 系统字体覆盖 Latin、波兰语变音字符和 CJK；标题约 22px，正文 14.5px／24px，最新句 19px／30px。
- 表单标签减少全大写式的宽字距；控件不因长翻译文字而缩小到难以阅读。

## 颜色职责

颜色通过语义资源统一管理，不在各个窗口重新指定品牌颜色。

| 资源 | 用途 |
|---|---|
| Sheet / Paper | 正文与暖色侧栏表面 |
| Ink / Ink2 / Ink3 | 正文、次级说明、元数据 |
| Brand / BrandHover / BrandPressed | 主操作、选中、聚焦与进度 |
| BrandWash | 浅色选中背景 |
| BrandAccent | Logo 的第二色，仅用于少量品牌细节 |
| OnBrand | 深色操作按钮上的文字和图标 |
| Rule / RuleFaint | 控件轮廓与内容分隔 |
| Record / Hold / Alarm | 录制、暂停与错误／危险，独立于品牌色 |

发言人的 rust／ochre／pine 继续表示人，不跟随主题替换。品牌色只作用于界面操作层。
色彩状态同时通过文字、形状、选中标记表达。浅色辅助色不承担小字正文或白字按钮底色。
正文与可操作控件文字以 4.5:1 为目标；焦点／关键控件轮廓以 3:1 为目标。

配色候选保存在 `design/brand-exploration/`：H 靛蓝＋杏橙、I 墨绿＋黄铜、J 酒红＋雾蓝。
这些是设计参考，不增加应用中的主题选择功能。

当前实现暂用 **H 靛蓝＋杏橙** 作为可替换的预览方案，尚未得到用户配色定稿确认。

| 浅色资源 | 色值 |
|---|---|
| Sheet / Paper | `#FFFCF7` / `#F5F0E6` |
| Ink / Ink2 / Ink3 | `#252B3B` / `#535969` / `#686D79` |
| Brand / Hover / Pressed | `#414B83` / `#35406F` / `#293359` |
| BrandWash / BrandAccent / OnBrand | `#EBEDF6` / `#EAA66A` / `#FFFFFF` |
| Rule / RuleFaint | `#CEC9C0` / `#E9E3D9` |

移动端深色背景为 `#181C28`，页头 `#222838`；文字为 `#F6F1E8`、`#BFC3D0`、`#A1A8BA`，
操作色提升到 `#B9C2FF`。Logo 使用暖白小底板，以保留深色模式下的双色情绪与识别度。

## 平台与行为边界

桌面主机仍使用显式浅色画刷。移动页面跟随系统明暗设置，资源内联，离线缓存逻辑不变。
图标交由 `design/kanal-icon.py` 打包到 ICO、ICNS、PNG 和内联 favicon；生成后的文件一并提交。
`web/index.html` 与 `docs/index.html` 必须逐字节相同。

本次是视觉更新。录制知情确认、暂停时停止送音频、最多四种语言、导入导出、发言人合并、
侧栏重命名和标题生成等现有行为不改变。不得将历史原型中的演示功能当成已交付能力。
