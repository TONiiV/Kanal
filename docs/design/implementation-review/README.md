## 实际验证

- `dotnet build Kanal.slnx`、`dotnet test`：见交付说明。
- Windows 11、125% 缩放：真实窗口启动，顶行连续，原生最小化/最大化/关闭在右上角，
  Avalonia 自绘的标题文字与全屏按钮已隐藏。
- 行为测试：语言聚焦（放大/恢复/切换会议/新房间/语言移除/列移动/直播持续接收）、
  顶栏留白归属、录制组居中（1900/1320/874 DIP）、右组固定右端并移出被裁控件的 Tab 顺序、
  460 DIP 隐藏状态词、放大后的列宽、应用语言旗标、新图标加载。

## 与设计的必要偏差

- 会议列表按“今天 / 昨天 / 最近”分组，每组可展开收起；标题下无“日期 / 项目”行、侧栏底部无
  “本地工作空间”字样：设计规范未定义这些，预览示例不代表现有能力。
- 窗口按钮是 Avalonia 在 58 DIP 顶行内绘制的 Windows 样式按钮，不是 HTML 预览的模拟按钮；
  悬停时最小化/最大化为整高浅色底，关闭为红底白叉（真实窗口 125% 缩放下确认）。
- 弹层用实色表面（Sheet、1 DIP 线、12 DIP 圆角）；Avalonia 弹层无背景模糊，按规范使用实色回退，
  未加阴影。
- 侧栏开关 180 ms 过渡未实现（列宽直接切换）；控件悬停 120 ms 渐变与录制 140 ms / 1.1 倍保留。
- 实时句不再用 3 DIP 发言人色顶线和放大字号，统一为 15/28 与细分隔线，部分句仍为弱化墨色。
- 减少动态效果：仅在 Windows（关闭客户区动画）探测，且只作用于主窗口。
