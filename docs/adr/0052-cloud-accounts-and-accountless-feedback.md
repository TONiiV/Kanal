# 账号控制云服务访问，反馈不要求账号

状态：accepted，2026-09-07。

Kanal 的本地功能免费，账号用于平台提供的云服务及未来订阅权益；用户将原先“反馈必须登录”的要求改为留联系邮箱即可提交，以降低反馈门槛。反馈入口因此独立承担防滥用校验，不能把账号认证当作其前置条件；有效的建议、Bug 和疑问统一由后端自动转入私有 GitHub issue，使用户无需 GitHub 账号或直接访问 GitHub。反馈采用首次邮箱验证并短期记住，云服务首版采用邀请与每账号额度；首版一次性赠送120分钟 Gladia 额度、每账号最多1个云任务，管理员可补额度且不自动续赠。支付订阅与付费实时 agent 留到后续阶段。
