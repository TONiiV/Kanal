# 01: 免登录邮箱验证反馈：齿轮、入口与私有收件

**What to build:** 用户从设置右侧对话气泡填写反馈，首次验证邮箱后获得持久化编号，无需注册。

**Blocked by:** #67.

**Status:** PR review — implementation not started

**Parent:** [账号云服务、免登录反馈、手机页托管与录音导入规格](../../specs/auth-feedback-relay-import.md)。

**User stories:** 1–12、14、17–18

- [ ] 齿轮与反馈矢量图标、键盘和无障碍操作齐全，沿用现有语言支持。
- [ ] 类别、标题、正文、邮箱完整；版本信息预览后可附带，首版无附件。
- [ ] 服务端验证绑定邮箱且限时的凭证，限制内容/提交/验证码频率；共享网络误拦可恢复。
- [ ] 匿名记录无伪造账号身份；服务端时间和私有存储；重复提交不重复收件，成功必须已有持久化编号。
- [ ] 行为测试覆盖验证码错误/过期、匿名成功、限流、越权读取和失败重试。
