# 06: 录音导入为所选会议的附件

> 2026-10-07 修订：原题为“录音导入当前工作空间并持久化为待转写会议”。导入的录音不再新建会议记录或待转写会议。录音成为用户所选会议的附件（ADR 0054 决定 20–21）。附件录音是否转写、如何转写，尚未决定，不在本票范围。

**What to build:** 用户选择一场已有会议并导入本地录音。录音副本成为该会议的附件。重启后附件仍在该会议中。导入本身不上传。

**Blocked by:** #68、#69.

**Status:** PR review — implementation not started

**Parent:** [账号云服务、免登录反馈、手机页托管与录音导入规格](../../specs/auth-feedback-relay-import.md)。

**User stories:** 37–40、42、45–46

- [ ] 实际支持 WAV/MP3/M4A，文件同时最多60分钟和500MB；解码/大小/时长失败早期报错。
- [ ] 复制到所选会议的 `attachments/` 目录，不删除源文件，不覆盖其他会议，拒绝越界路径。
- [ ] 取消或复制失败不留下不完整的附件；缺失/损坏文件给出可操作错误。
- [ ] 导入不新建会议记录或待转写会议；附件重启后仍可从所属会议打开。导入不上传，也不启动转写。
- [ ] 真实短音频和临时目录覆盖导入/重启/隔离/失败与边界，并验证会议记录数量不变；避免长音频无界整文件读内存。
