# 06: 录音导入当前工作空间并持久化为待转写会议

**What to build:** 用户导入本地录音，得到包含原音副本的待转写会议，重启可打开且导入本身不上传。

**Blocked by:** #68、#69.

**Status:** PR review — implementation not started

**Parent:** [账号云服务、免登录反馈、手机页托管与录音导入规格](../../specs/auth-feedback-relay-import.md)。

**User stories:** 37–40、42、45–46

- [ ] 实际支持 WAV/MP3/M4A，文件同时最多60分钟和500MB；解码/大小/时长失败早期报错。
- [ ] 复制到所属会议目录，不删除源文件，不覆盖其他会议，拒绝越界路径。
- [ ] 取消或复制失败不留下完成假象；缺失/损坏文件给出可操作错误。
- [ ] 持久化记录及音频引用，重启可恢复；云处理手动开始，未配置时诚实说明。
- [ ] 真实短音频和临时目录覆盖导入/重启/隔离/失败与边界，避免长音频无界整文件读内存。
