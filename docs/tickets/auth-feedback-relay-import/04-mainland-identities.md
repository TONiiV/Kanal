# 04: 微信、手机号登录绑定及大陆可靠登录路径

**What to build:** 微信和手机号可以登录或绑定现有账号，大陆普通网络至少有可靠登录路径。

**Blocked by:** T03.

**Status:** PR review — implementation not started

**Parent:** [账号云服务、免登录反馈、手机页托管与录音导入规格](../../specs/auth-feedback-relay-import.md)。

**User stories:** 22–26、52

- [ ] 验证微信接入与目标租户 +86 短信，必要时按授权适配或替换 Clerk。
- [ ] 身份绑定必须验证控制权，不重复创建权益账号；错误/过期验证码和身份已占用状态明确。
- [ ] 完成真实大陆网络的登录与短信验证，记录网络/设备及失败；不能以官方支持列表代替实测。
- [ ] Google 在其服务可访问的网络使用；国内可靠路径不等于删除其他所要求的登录方式。
- [ ] 已存在双账号冲突人工处理；账号恢复/解除绑定保持可验证的访问途径。
