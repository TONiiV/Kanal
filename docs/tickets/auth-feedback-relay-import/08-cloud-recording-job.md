# 08: 受邀用户云转写录音：取消、重试、落盘与清理

**What to build:** 有 GPU 试用权限的用户明确启动云转写，查看进度并取消/重试，结果保存回所属会议。

**Blocked by:** T05、T06、T07.

**Status:** PR review — implementation not started

**Parent:** [账号云服务、免登录反馈、手机页托管与录音导入规格](../../specs/auth-feedback-relay-import.md)。

**User stories:** 40–43、45–49

- [ ] 上传前披露云处理并验证账号权限/并发，GPU 计量与 Gladia 分钟分开。
- [ ] 等待、上传/处理、完成、失败和取消可区分，EOF 不等于最终结果完成。
- [ ] 结果含原文、说话人和有效输入时间戳，关联本会议原音并可重启恢复。
- [ ] 重试不重复提交同一任务或记账；取消/失败保留本地音频，服务端拒绝跨账号资源访问。
- [ ] 结果可靠保存后删除临时音频，失败最多24小时，清理不依赖桌面在线。
- [ ] 行为测试覆盖生命周期/清理，受控真实验证完整往返；模型不达标不能静默换服务宣称完成。
